Pitch Shape Lab: MLB Comps & Whiff Model
baseball / sports analytics

Turns a TrackMan bullpen export into a scouting-style report on every pitch. Pulled the full 2025 Statcast season from Baseball Savant (707K pitches, 829 pitchers), normalized every pitch to the pitcher's arm side so lefties and righties compare directly, and built a reference of each MLB pitcher's arsenal. Each of your pitches gets its five closest MLB comps on velocity, induced vertical break, horizontal break, spin, release height and extension, along with how those comps actually performed (whiff rate, run value). A gradient-boosted model trained on 336K MLB swings predicts each pitch's swing-and-miss rate from its shape, release and separation off the fastball, validated on pitchers held out of training. Switch between pitchers and filter by date range; everything recomputes in the browser.

5MLB comps per pitch

Rebuilt from my original 440-pitch comparison tool: real Statcast data instead of a hand-built list, multi-feature comps instead of break alone, and outcomes (whiff%, run value) instead of shape only.

Reviewdle: Guess the Movie
web app / game design

A daily Wordle-style guessing game where you identify a movie from a sequence of real reviews. I built it as a single-page vanilla JavaScript app on top of a dataset of over 1,600 movies and 5,500+ real reviews sourced from the TMDB and Trakt APIs, with a date-seeded hash so every player gets the same daily puzzle. It includes a custom-built autocomplete (native HTML datalists crash on mobile Safari with a dataset this large, so I wrote my own), decade-filtered random mode, localStorage-backed win/streak tracking, and Wordle-style shareable results. Bought the domain, wrote the full Open Graph and favicon setup, and deployed it myself via GitHub Pages.

Minimum Spanning Tree Library
algorithms / C++

Implemented Kruskal's and lazy Prim's algorithms from scratch in C++ to find minimum spanning trees on weighted, undirected graphs, built on top of a custom union-find structure with path compression and union by size, and STL priority queues for edge selection. Verified correctness against an independent reference implementation across multiple test graphs, then optimized Prim's implementation to scan adjacency lists instead of the full edge set, cutting unnecessary work per vertex.
