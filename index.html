MLB Pitch Shape Comparison Tool
baseball / sports analytics

Built a Python tool that takes an amateur pitcher's Trackman-style metrics (velocity, spin rate, horizontal and vertical break) and finds the closest-shaped comp for each pitch from a reference set of 440 real MLB pitches. Wrote a PitchingMetrics class to summarize a pitcher's arsenal by pitch type, then matched each one to its nearest MLB neighbor by shape distance in break-space. Results render into a two-tab HTML dashboard: a summary table with a pitch-shape plot, and a side-by-side comparison table linking out to each matched pitcher's Baseball Savant page.

440MLB reference pitches
5+pitch types analyzed
2dashboard views (summary + comps)

Still iterating on the matching logic — next up is factoring in spin axis alongside break for a tighter shape match.

Predicting Formula One Results
motorsports / regression analysis

Statistics project (co-developed with a classmate) predicting a driver's final race position from over 26,000 rows of Formula One results spanning 1970–2023, filtered down to ~2,300 points with reliable pit-stop data. Built a first-order model with a weather–driver interaction term, then a second-order model to improve fit, and used forward stepwise regression to simplify it into a cleaner final model — balancing predictive power against overfitting.

Minimum Spanning Tree Library
algorithms / C++

Implemented Kruskal's and lazy Prim's algorithms from scratch in C++ to find minimum spanning trees on weighted, undirected graphs — built on top of a custom union-find structure with path compression and union by size, and STL priority queues for edge selection. Verified correctness against an independent reference implementation across multiple test graphs, then optimized Prim's implementation to scan adjacency lists instead of the full edge set, cutting unnecessary work per vertex.
